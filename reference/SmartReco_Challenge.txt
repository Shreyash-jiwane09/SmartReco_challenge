============================================================
PROJECT OVERVIEW
============================================================

Build an enterprise-grade behavioral AI recommendation platform.

The platform observes user behavior, understands user interests,
retrieves relevant products using semantic search, and generates
personalized persuasive recommendations using AI.

The system should continuously improve recommendations as user
behavior evolves.

============================================================
PROJECT STORY
============================================================

A user browses the platform.

The system tracks meaningful interactions such as:

- Product views
- Searches
- Clicks
- Time spent

The recommendation agent analyzes this behavioral history.

The agent retrieves the most relevant products using semantic search
over a vector database.

The AI then generates a personalized recommendation containing:

- A persuasive narrative
- Relevant products
- Motivation to take action

Recommendations are stored and updated whenever user interests change.

(Optional)

Recommendations may also be delivered proactively through scheduled
email or Telegram notifications.

============================================================
MANDATORY REQUIREMENTS
============================================================

1. Platform Foundation

• Email/password authentication
• Two roles
    - User
    - Admin
• Product browsing
• Recommendation page
• Admin dashboard

------------------------------------------------------------

2. Database

Design a proper relational schema containing:

• Users
• Products
• Activity / Events
• Recommendations

------------------------------------------------------------

3. Product Management

Admin can

• Create products
• Update products
• Delete products

Every product must be written to

• SQL Database
AND
• Vector Database

Both stores must remain synchronized.

------------------------------------------------------------

4. Behavioral Event Tracking

Track meaningful user behavior

• Product views
• Searches
• Clicks
• Time spent

Requirements

• Non-blocking
• Efficient
• Batched when appropriate
• Does not slow the frontend

Store

• User
• Event
• Timestamp

------------------------------------------------------------

5. Agentic Recommendation Engine

The backend AI agent should

• Analyze user behavior
• Understand interests
• Retrieve relevant products using semantic search
• Generate persuasive recommendations
• Recommend real catalog products only
• Store recommendations
• Refresh recommendations as behavior evolves

------------------------------------------------------------

6. Production Thinking

The implementation should

• Avoid unnecessary LLM calls
• Use meaningful AI triggers
• Cache expensive operations
• Batch event writes
• Avoid redundant processing
